SHIPPED - v0.1.0 - Phase 1: Foundation
============================================================================

Authentication (FR-AUTH)
  [x] FR-AUTH-001  Sign in with GitHub (OAuth App, no scopes, single-use state)
  [x] FR-AUTH-002  Authenticated session (HTTP-only cookie, CSRF, expiry, /auth/me)
  [x] FR-AUTH-003  Disconnect GitHub (revoke grant, delete credential, sign out)
  [x] Logout (session ended; GitHub link kept)
  [x] Audit log for sign-in, failed sign-in, logout, disconnect

Credential security
  [x] GitHub token encrypted at rest (MultiFernet, key rotation)
  [x] Token never in API responses, URLs or logs (log redaction filter as backstop)
  [x] Startup blocked when encryption keys are missing or invalid

API platform
  [x] Versioned base path /api/v1/
  [x] OpenAPI schema (/api/v1/schema/) + generated TypeScript types
  [x] Standard error envelope {"error": {code, message, details}}
  [x] Authenticated by default (401), CSRF on state-changing requests
  [x] Rate limiting (429 + Retry-After), stricter on sign-in
  [x] CORS allowlist + security headers (nosniff, DENY framing, referrer policy, HSTS in prod)
  [x] Health check (database, Redis; Redis "not_configured" in local mode)

Frontend
  [x] Landing page with "Continue with GitHub" and sign-in error messages
  [x] Route guard for signed-in pages
  [x] Signed-in shell: identity, logout, disconnect with confirmation

Developer experience
  [x] npm run setup / npm start (local PostgreSQL, Redis optional)
  [~] Docker Compose stack (built; not yet verified - no Docker on the dev machine)
  [x] CI: lint, types, tests, build, API schema drift, version consistency
